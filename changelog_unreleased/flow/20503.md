#### Remove extra indention in "match" expression head (#20503 by @fisker)

```flow
// Input
x = match ($veryLongAndVeryVerboseVariableName && $anotherVeryLongAndVeryVerboseVariableName) {
};

// Prettier stable
x = match (
  $veryLongAndVeryVerboseVariableName &&
    $anotherVeryLongAndVeryVerboseVariableName
) {
};

// Prettier main
x = match (
  $veryLongAndVeryVerboseVariableName &&
  $anotherVeryLongAndVeryVerboseVariableName
) {
};
```
