#### Preserve Flow declaration signatures and property syntax (#20385 by @gkz)

Prettier now preserves anonymous ambient default-export function signatures, declared constructors without return annotations, literal initializers on readonly declared-class fields, and optional Flow indexers when using the `flow` parser. Quoted methods named `"new"` retain their quotes so formatting does not turn them into construct signatures. Construct signatures also keep their unquoted spelling with `quoteProps: "consistent"`.

The anonymous default-export function example is from a `.js.flow` declaration file.

<!-- prettier-ignore -->
```flow
// Input (example.js.flow)
export default function (): void;

// Prettier stable
export default function ;

// Prettier main
export default function (): void;
```

<!-- prettier-ignore -->
```flow
// Input
declare class C { constructor(); readonly x = 42; static readonly y = "value"; }

// Prettier stable
declare class C {
  constructor(): ;
  readonly x: ;
  static readonly y: ;
}

// Prettier main
declare class C {
  constructor();
  readonly x = 42;
  static readonly y = "value";
}
```

<!-- prettier-ignore -->
```flow
// Input
type T = { [key: string]?: number };

// Prettier stable
type T = { [key: string]: number };

// Prettier main
type T = { [key: string]?: number };
```

<!-- prettier-ignore -->
```flow
// Input
type Method = { 'new'(): string };
type Constructor = { new(): string };

// Prettier stable
type Method = { new(): string };
type Constructor = { new(): string };

// Prettier main
type Method = { "new"(): string };
type Constructor = { new(): string };
```
