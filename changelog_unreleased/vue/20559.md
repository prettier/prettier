#### Keep semicolons in event handlers with multiple statements (#20559 by @Strate)

Vue treats an event handler as statements only if it contains a `;`, so with `--no-semi` the output did not compile.

<!-- prettier-ignore -->
```vue
<!-- Input -->
<template>
  <button @click="foo = null; bar = false">x</button>
</template>

<!-- Prettier stable (--no-semi) -->
<template>
  <button
    @click="
      foo = null
      bar = false
    "
  >
    x
  </button>
</template>

<!-- Prettier main (--no-semi) -->
<template>
  <button
    @click="
      foo = null;
      bar = false;
    "
  >
    x
  </button>
</template>
```
