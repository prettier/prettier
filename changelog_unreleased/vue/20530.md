#### Keep semicolons in Vue event handlers with multiple statements (#20530 by @yuvaraj-2006)

Vue only compiles an inline event handler as statements when it contains `;`, so removing them with `--no-semi` produced templates that failed to compile.

<!-- prettier-ignore -->
```html
<!-- Input -->
<template>
  <button @click="firstName = ''; lastName = ''">Clear</button>
</template>

<!-- Prettier stable (--no-semi) -->
<template>
  <button
    @click="
      firstName = ''
      lastName = ''
    "
  >
    Clear
  </button>
</template>

<!-- Prettier main (--no-semi) -->
<template>
  <button
    @click="
      firstName = '';
      lastName = '';
    "
  >
    Clear
  </button>
</template>
```
