#### Preserve double-brace placeholders inside string literals (#20117 by @splincode)

<!-- prettier-ignore -->
```html
<!-- Input -->
<template>
  <div>{{"{{first}} / {{second}} files selected"}}</div>
</template>

<!-- Prettier stable -->
<template>
  <div>{{"{{first}} / {{ second }} files selected"}}</div>
</template>

<!-- Prettier main -->
<template>
  <div>{{ "{{first}} / {{second}} files selected" }}</div>
</template>
```
