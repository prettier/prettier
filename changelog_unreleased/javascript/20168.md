#### Keep line comments after the opening JSX bracket on a new line (#20168 by @charan-rathore)

A line comment between `<` and a JSX tag name now stays on its own line. The output can be parsed and formatted again.

<!-- prettier-ignore -->
```jsx
// Input
const a = <
  // c
  div />;

// Prettier stable
const a = (
  <// c
  div
  />
);

// Prettier main
const a = (
  <
    // c
    div
  />
);
```
