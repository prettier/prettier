#### Fix unstable trailing comment on a parenthesized arrow body (#20008 by @Kjubikstronk)

The parentheses around the body are dropped, which leaves the comment next to the statement's semicolon. The next format then attaches it to the statement rather than to the body it was written against.

<!-- prettier-ignore -->
```jsx
// Input
x2 = (a) => (a /* ! */
)

// Prettier stable (first format)
x2 = (a) => a /* ! */;

// Prettier stable (second format)
x2 = (a) => a; /* ! */

// Prettier main
x2 = (a) => a; /* ! */
```
