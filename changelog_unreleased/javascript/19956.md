#### Fix unstable trailing comment in a parenthesized arrow function body (#19956 by @lazerg)

A comment before the closing parenthesis of an arrow function body was read as a comment on the last parameter, and the parentheses it belonged to are dropped anyway, so the next format moved it past the semicolon.

<!-- prettier-ignore -->
```jsx
// Input
x2 = (a) => (a /* ! */ // K
)

// Prettier stable (First format)
x2 = (a) =>
  a /* ! */; // K

// Prettier stable (Second format)
x2 = (a) => a; /* ! */ // K

// Prettier main
x2 = (a) => a; /* ! */ // K
```
