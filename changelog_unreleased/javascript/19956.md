#### Fix unstable trailing comment in a parenthesized arrow function body (#19956 by @lazerg)

A comment before the closing parenthesis of an arrow function body is read as a comment on the last parameter, even though the node before the parenthesis is the body. The parentheses are dropped anyway, so the next format moves the comment past the semicolon.

<!-- prettier-ignore -->
```jsx
// Input
x2 = (a) => (a /* ! */ // K
)

// Prettier stable (First format)
x2 = (a) =>
  a /* ! */; // K

// Prettier stable (Second format)
x2 = (a) => a; /* ! */ // K

// Prettier main
x2 = (a) => a; /* ! */ // K
```
