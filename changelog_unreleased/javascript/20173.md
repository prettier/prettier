#### Don't duplicate comments on a JSX superclass (#20173 by @Yahiro025)

<!-- prettier-ignore -->
```jsx
// Input
class A extends (/* c */ <div />) {}

class B extends (<div /> /* c */) {}

// Prettier stable
class A extends /* c */ (/* c */ <div />) {}

class B extends (<div /> /* c */) /* c */ {}

// Prettier main
class A extends (/* c */ <div />) {}

class B extends (<div /> /* c */) {}
```
