#### Detect `@format` and `@prettier` written as line comments in JavaScript (#20289 by @Hamza0101)

Pragma detection only read the leading `/* */` block, so `--require-pragma` skipped a file whose pragma was a line comment. A pragma after real code is still ignored.

<!-- prettier-ignore -->
```jsx
// Input
// @format
foo (  1 )

// Prettier stable
// @format
foo (  1 )

// Prettier main
// @format
foo(1);
```
