#### Treat zero-width format characters as zero-width in `getStringWidth` (#20081 by @tgfjt)

Characters with the `Default_Ignorable_Code_Point` property (eg ZWSP, ZWJ, tags, BOM) no longer count towards `printWidth`.

<!-- prettier-ignore -->
```jsx
// Input
fit(["0123456789", "0123456789", "0123456789", "0123456789", "0123456789abcd​"]);

// Prettier stable
fit([
  "0123456789",
  "0123456789",
  "0123456789",
  "0123456789",
  "0123456789abcd​",
]);

// Prettier main
fit(["0123456789", "0123456789", "0123456789", "0123456789", "0123456789abcd​"]);
```
