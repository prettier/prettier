#### Avoid duplicated comments on JSX class superclasses (#20191 by @Rober1208)

Comments inside a JSX class superclass's parentheses are printed once and remain stable on subsequent formatting passes.

<!-- prettier-ignore -->
```jsx
// Input
class A extends (<Tag /> /* comment */) {}

// Prettier stable
class A extends (<Tag /> /* comment */) /* comment */ {}

// Prettier main
class A extends (<Tag /> /* comment */) {}
```
