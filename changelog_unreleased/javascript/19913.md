#### Keep parentheses when a comment would break a `yield` expression (#19913 by @giaBaoJS)

`yield` is a restricted production: no line terminator is allowed between `yield` and its argument. A leading comment that ends up on its own line introduces one, so the parentheses have to be kept. The `yield` argument now goes through the same printer as `return` and `throw`, so a long argument that breaks is wrapped in parentheses too.

<!-- prettier-ignore -->
```jsx
// Input
function* f() {
  yield (/*
  */ a);
}

// Prettier stable
function* f() {
  yield /*
   */ a;
}

// Prettier main
function* f() {
  yield (
    /*
     */ a
  );
}
```
