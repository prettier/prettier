#### Keep parentheses when a comment would break a `yield` expression (#19913 by @giaBaoJS)

`yield` is a restricted production: no line terminator is allowed between `yield` and its argument. A comment spanning lines counts as one, so the parentheses have to be kept.

<!-- prettier-ignore -->
```jsx
// Input
function* f() {
  yield (/*
  */ a);
}

// Prettier stable
function* f() {
  yield /*
   */ a;
}

// Prettier main
function* f() {
  yield (
    /*
     */ a
  );
}
```
