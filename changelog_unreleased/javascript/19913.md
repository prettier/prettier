#### Keep parentheses when a comment would break a restricted production (#19913 by @giaBaoJS)

`yield` and postfix `++`/`--` are restricted productions: no line terminator is allowed between `yield` and its argument, or between the argument and the operator. A comment spanning lines counts as one, so the parentheses have to be kept.

<!-- prettier-ignore -->
```jsx
// Input
(a/*
*/)++;

function* f() {
  yield (/*
  */ a);
}

// Prettier stable
a /*
 */++;

function* f() {
  yield /*
   */ a;
}

// Prettier main
(a /*
 */)++;

function* f() {
  yield (
    /*
     */ a
  );
}
```
