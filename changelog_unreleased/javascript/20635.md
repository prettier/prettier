#### Keep own-line comments before `.property` in member expressions (#20635 by @YusufMntm)

<!-- prettier-ignore -->
```jsx
// Input
blablablablablablablabla.hellohellohellohellohellohellohellohellohellohello
  // @ts-expect-error
  .dayOfWeek;

// Prettier stable
// @ts-expect-error
blablablablablablablabla.hellohellohellohellohellohellohellohellohellohello
  .dayOfWeek;

// Prettier main
blablablablablablablabla.hellohellohellohellohellohellohellohellohellohello
  // @ts-expect-error
  .dayOfWeek;
```
