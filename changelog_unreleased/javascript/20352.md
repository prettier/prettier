#### Print `;` before the type cast comment of a `prettier-ignore`d statement (#20352 by @vidigoat)

<!-- prettier-ignore -->
```jsx
// Input
foo;
// prettier-ignore
/** @type {string[]} */ (cast).sort();

// Prettier stable (--no-semi)
foo
// prettier-ignore
/** @type {string[]} */ ;(cast).sort()

// Prettier main (--no-semi)
foo
// prettier-ignore
;/** @type {string[]} */ (cast).sort()
```
