#### Align closing parentheses for experimental ternaries in member chains (#20242 by @Suwanwa)

When a parenthesized ternary is indented onto a new line before a member access, put its closing parenthesis at the surrounding indentation. This also applies to optional member access. The example uses `experimentalTernaries: true` and `printWidth: 72`.

<!-- prettier-ignore -->
```jsx
// Input
const hexColor = (
  rawColor.startsWith("#") ? rawColor : `#${rawColor}`
).toLowerCase();

// Prettier stable
const hexColor = (
  rawColor.startsWith("#") ? rawColor : `#${rawColor}`).toLowerCase();

// Prettier main
const hexColor = (
  rawColor.startsWith("#") ? rawColor : `#${rawColor}`
).toLowerCase();
```
