#### Avoid unnecessary semicolons before private members named `#in` or `#instanceof` (#20019 by @cellison-figma)

<!-- prettier-ignore -->
```js
// Input
class Graph {
  #nodes = {};
  #in = {};
}

// Prettier stable (--parser acorn --no-semi)
class Graph {
  #nodes = {};
  #in = {}
}

// Prettier main (--parser acorn --no-semi)
class Graph {
  #nodes = {}
  #in = {}
}
```

_Non-Babel parsers (flow, acorn, etc.) are affected._
