#### Remove duplicated parentheses in ternaries printed in JSX mode (#19857 by @juapperez)

Ternaries containing JSX wrap their consequent and alternate in parentheses when they break. Nodes that print parentheses of their own, like nullish coalescing (#16391) or `as` expressions, ended up with two pairs of them.

<!-- prettier-ignore -->
```jsx
// Input
const value = condition ? (
  <Example /> // comment
) : (
  "alpha" ?? "bravo"
);

// Prettier stable
const value = condition ? (
  <Example /> // comment
) : (
  ("alpha" ?? "bravo")
);

// Prettier main
const value = condition ? (
  <Example /> // comment
) : (
  "alpha" ?? "bravo"
);
```
