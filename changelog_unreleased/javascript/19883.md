#### Keep a trailing comment inside a for-in or for-of head (#19883 by @Kjubikstronk)

<!-- prettier-ignore -->
```jsx
// Input
for (
  let i of a // Hello
) {
}

// Prettier stable (first format)
for (let i of a) { // Hello
}

// Prettier stable (second format)
for (let i of a) {
  // Hello
}

// Prettier main
for (
  let i of a // Hello
) {
}
```
