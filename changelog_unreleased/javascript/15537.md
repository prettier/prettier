#### Fix unstable trailing comment inside dropped parentheses (#15537 by @diptomistry)

Trailing comments that sat inside parentheses Prettier drops (for example on the
right-hand side of a `const` init) were attached to the inner expression on the
first format and to the statement on the second, which moved them past the
semicolon. They are now attached to the statement immediately, matching the
already-stable un-parenthesized form.

<!-- prettier-ignore -->
```jsx
// Input
const AUTHORIZATION_TOKEN_VALIDITY =
  (24 * hours /* docs */) - (1 * hours /* buffer */);

// Prettier stable (First format)
const AUTHORIZATION_TOKEN_VALIDITY =
  24 * hours /* docs */ - 1 * hours /* buffer */;

// Prettier stable (Second format)
const AUTHORIZATION_TOKEN_VALIDITY =
  24 * hours /* docs */ - 1 * hours; /* buffer */

// Prettier main
const AUTHORIZATION_TOKEN_VALIDITY =
  24 * hours /* docs */ - 1 * hours; /* buffer */
```
