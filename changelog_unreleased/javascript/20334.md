#### Stabilize formatting of JSDoc-cast member expressions (#20334 by @JakkulaVeerababu)

Closure-style type cast comments on a member expression used as a unary argument
now retain their intended parentheses after one formatting pass.

<!-- prettier-ignore -->
```jsx
// Input
function t(window) {
  delete (/** @type {any} */ window).__pwned;
}

// Prettier stable
function t(window) {
  delete /** @type {any} */ window.__pwned;
}

// Prettier main
function t(window) {
  delete /** @type {any} */ (window).__pwned;
}
```
