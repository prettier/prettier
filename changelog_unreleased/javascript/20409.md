#### Avoid stack overflows when formatting long binary expressions (#20409 by @splincode)

Prettier now formats long chains of binary operators without overflowing the JavaScript call stack. Previously, formatting thousands of concatenated strings could fail with a `RangeError`.

<!-- prettier-ignore -->
```js
const source = Array.from({ length: 1800 }, () => '"a"').join(" + ");

// Prettier stable
await prettier.format(source, { parser: "meriyah" });
// RangeError: Maximum call stack size exceeded

// Prettier main
await prettier.format(source, { parser: "meriyah" });
// Successfully formats all 1,800 operands
```
