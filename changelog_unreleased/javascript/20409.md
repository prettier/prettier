#### Avoid stack overflows when formatting long binary expressions (#20409 by @splincode)

Prettier now formats long chains of binary operators without overflowing the JavaScript call stack. Previously, formatting thousands of operands could fail with a `RangeError`.

<!-- prettier-ignore -->
```js
// Prettier stable
await prettier.format("a + ".repeat(2000) + "a", { parser: "babel" });
// RangeError: Maximum call stack size exceeded

// Prettier main
await prettier.format("a + ".repeat(2000) + "a", { parser: "babel" });
// 'a +\n' +
//  '  a +\n' +
//  '  a +\n'... 2003 more characters
```
