#### Fix unstable trailing comment on a parenthesized arrow body (#20075 by @Maher-Reven)

The parentheses around the body are dropped, so the comment ends up next to the statement's semicolon, where the next format attaches it to the statement instead of to the body it was written against.

<!-- prettier-ignore -->
```jsx
// Input
x2 = (a) => (a /* ! */ // K
)

// Prettier stable (First format)
x2 = (a) =>
  a /* ! */; // K

// Prettier stable (Second format)
x2 = (a) => a; /* ! */ // K

// Prettier main
x2 = (a) => a; /* ! */ // K
```

A conditional body keeps its parentheses, so a block comment written inside them now stays there, as it already did when no line comment followed it.

<!-- prettier-ignore -->
```jsx
// Input
x2 = (a) => (b ? c : d /* ! */ // K
)

// Prettier stable
x2 = (a) => (b ? c : d); /* ! */ // K

// Prettier main
x2 = (a) => (b ? c : d /* ! */); // K
```
