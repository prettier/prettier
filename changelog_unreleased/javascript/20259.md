#### Fix unstable comments in labeled expressions (#20259 by @jum-apzn)

Leading comments inside a parenthesized labeled expression are now placed before the label on the first format, rather than moving there on a second format. This also applies to consecutive labels.

<!-- prettier-ignore -->
```jsx
// Input
{
  foo: (
    // comment
    {
      bar: "baz",
    }
  )
}

// Prettier stable
{
  foo: // comment
  ({
    bar: "baz",
  });
}

// Prettier main
{
  // comment
  foo: ({
    bar: "baz",
  });
}
```
