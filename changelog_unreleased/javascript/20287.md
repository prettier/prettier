#### Preserve required semicolons when unquoting property names (#20287 by @Rahul5914)

With `semi: false`, removing quotes from keyword property names could produce invalid JavaScript or TypeScript. Prettier now checks the key's printed form before deciding whether a semicolon is required.

<!-- prettier-ignore -->
```tsx
// Input (--parser typescript --no-semi)
class C {
  x = a
  "in"() {}
}

interface I {
  "get"
  a: string
}

// Prettier stable
class C {
  x = a
  in() {}
}

interface I {
  get
  a: string
}

// Prettier main
class C {
  x = a;
  in() {}
}

interface I {
  get;
  a: string
}
```
