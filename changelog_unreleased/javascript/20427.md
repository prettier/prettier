#### Add support for "Structs" proposal (#20427 by @fisker)

The Stage 2 proposal ["Structs"](https://github.com/tc39/proposal-structs) is now supported via Babel. Also keep in mind our [policy on non-standardized syntax](https://prettier.io/docs/en/rationale.html#disclaimer-about-non-standard-syntax) before using this proposed syntax feature with Prettier.

<!-- prettier-ignore -->
```jsx
struct Point {
  x = 0;
  y = 0;

  get length() {
    return Math.hypot(this.x, this.y);
  }
}
```
