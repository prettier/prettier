#### Add support for "Structs", "Import Sync" proposal (#20427, #20430 by @fisker)

Prettier main added support for new ES proposals.

- ["Structs"](https://github.com/tc39/proposal-structs) proposal (Only non-shared structs)

  ```jsx
  struct Point {
    x = 0;
    y = 0;

    get length() {
      return Math.hypot(this.x, this.y);
    }
  }
  ```

- [`Import Sync`](https://github.com/tc39/proposal-import-sync) proposal

  ```jsx
  const { readFile } = import.sync("node:fs");
  ```

Please keep in mind our [policy on non-standardized syntax](https://prettier.io/docs/en/rationale.html#disclaimer-about-non-standard-syntax) before using these proposed syntax features with Prettier.
