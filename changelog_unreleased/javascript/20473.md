#### Preserve blank lines between dangling comments (#20473 by @adityajai119)

<!-- prettier-ignore -->
```jsx
// Input
function foo() {
  // comment 1

  // comment 2
}

// Prettier stable
function foo() {
  // comment 1
  // comment 2
}

// Prettier main
function foo() {
  // comment 1

  // comment 2
}
```

_The same fix applies to TypeScript, Flow and GraphQL._
