#### Format ternary expressions in binary expressions (#5682 by @johnhldiver-beep)

<!-- prettier-ignore -->
```js
// Input
const a3 =
  (funnelSnapshotCard
    ? loremInpsumDolorSitAmetConsectetur()
    : somethingElseWithReallyLongMeaninglessName()) + 100;

// Prettier stable
const a3 =
  (funnelSnapshotCard
    ? loremInpsumDolorSitAmetConsectetur()
    : somethingElseWithReallyLongMeaninglessName()) + 100;

// Prettier main
const a3 =
  (funnelSnapshotCard
    ? loremInpsumDolorSitAmetConsectetur()
    : somethingElseWithReallyLongMeaninglessName()
  ) + 100;
```

The closing paren of a parenthesized ternary expression that breaks now goes on its own line when the ternary is an operand of a binary expression (e.g., `+`, `-`, `&&`, `||`). This makes the operator attach to the whole parenthesized expression.
