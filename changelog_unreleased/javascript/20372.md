#### Align logical expressions in `AwaitExpression` with `ReturnStatement` (#20372 by @erenbati)

Prettier now breaks long logical expressions inside `await` parentheses, consistently with `return` and `yield`. Previously, the first operand stayed on the same line as `await` and the closing parenthesis did not get its own line.

<!-- prettier-ignore -->
```jsx
// Input
async function* f() {
  await (
    aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa &&
    bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb &&
    cccccccccccccccc
  );
}

// Prettier stable
async function* f() {
  await (aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa &&
    bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb &&
    cccccccccccccccc);
}

// Prettier main
async function* f() {
  await (
    aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa &&
    bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb &&
    cccccccccccccccc
  );
}
```
