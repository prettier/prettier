#### Avoid extra blank lines in nested JSX attribute ternaries (#20240 by @Suwanwa)

With `experimentalTernaries`, nested conditional expressions in JSX attributes no longer receive the layout intended for JSX child expressions. This removes an unwanted blank line before the closing brace and prevents blank lines from accumulating before a trailing comment on successive formatting passes.

<!-- prettier-ignore -->
```jsx
// Input
const foo = (
  <Foo
    prop={
      bar ? "bar"
      : baz ?
        "baz"
      : <Bar
          prop={"This is a really long value to make sure that this wraps"}
        />
      //comment
    }
  />
);

// Prettier stable (experimentalTernaries: true)
const foo = (
  <Foo
    prop={
      bar ? "bar"
      : baz ?
        "baz"
      : <Bar
          prop={"This is a really long value to make sure that this wraps"}
        />

      //comment
    }
  />
);

// Prettier main (experimentalTernaries: true)
const foo = (
  <Foo
    prop={
      bar ? "bar"
      : baz ? "baz"
      : <Bar
          prop={"This is a really long value to make sure that this wraps"}
        />
      //comment
    }
  />
);
```
