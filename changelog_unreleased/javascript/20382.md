#### Count tabs in template literal text toward `printWidth` (#20382 by @lazerg)

Tabs in printed text were measured as zero width, so an interpolation after tab indented template text could go past `printWidth`. Each tab now moves to the next `tabWidth` stop.

<!-- prettier-ignore -->
```jsx
// Input
const html = `
	<div>
		<ul>
			${
				items.map((item) => `<li>${item.displayName} (${item.id})</li>`).join("")
			}
		</ul>
	</div>
`;

// Prettier stable (--use-tabs)
const html = `
	<div>
		<ul>
			${items.map((item) => `<li>${item.displayName} (${item.id})</li>`).join("")}
		</ul>
	</div>
`;

// Prettier main (--use-tabs)
const html = `
	<div>
		<ul>
			${items
				.map((item) => `<li>${item.displayName} (${item.id})</li>`)
				.join("")}
		</ul>
	</div>
`;
```
