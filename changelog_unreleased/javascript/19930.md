#### Fix unstable trailing comment on a parenthesized arrow chain (#19930 by @Kjubikstronk)

The parentheses around the inner arrow are redundant, so they are dropped. That leaves the comment next to the statement's semicolon, where the next format attaches it to the statement instead of to the arrow it was written against.

<!-- prettier-ignore -->
```jsx
// Input
x2 = (a) => ((b) => {
  c();
} /* ! */ // K
)

// Prettier stable (first format)
x2 = (a) => (b) => {
  c();
} /* ! */; // K

// Prettier stable (second format)
x2 = (a) => (b) => {
  c();
}; /* ! */ // K

// Prettier main
x2 = (a) => (b) => {
  c();
}; /* ! */ // K
```
