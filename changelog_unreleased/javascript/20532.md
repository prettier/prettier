#### Keep Flow comment types before class field semicolons (#20532 by @Erfouni)

Preserve inline Flow comment annotations on class fields when formatting JavaScript.

<!-- prettier-ignore -->
```js
// Input
class Worker {
  #plugins /*: ReadonlyArray<MetadataWorker> */;
}

// Before this change
class Worker {
  #plugins; /*: ReadonlyArray<MetadataWorker> */
}

// After this change
class Worker {
  #plugins /*: ReadonlyArray<MetadataWorker> */;
}
```
