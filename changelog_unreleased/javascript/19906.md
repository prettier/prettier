#### Fix stack overflow when formatting deeply-nested binary/logical chains (#19906 by @dineshyadav03)

Prettier threw `RangeError: Maximum call stack size exceeded` on inputs with a few thousand chained binary/logical operators (e.g. a long chain of `+`-concatenated string literals), because flattening the chain and walking embedded-language nodes both used native recursion whose depth scaled with the input. Both are now iterative, so Prettier no longer crashes on this shape of input.

<!-- prettier-ignore -->
```jsx
// Input
const x = "a" + "b" + "c" /* ...thousands more... */ + "z";

// Prettier stable
// RangeError: Maximum call stack size exceeded

// Prettier main
const x =
  "a" +
  "b" +
  "c" +
  /* ...thousands more... */
  "z";
```
