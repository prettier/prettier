#### Break long single-line template literals after `=`, like string literals (#20383 by @calvinjuarez, @abrahamguo)

A template literal on the right side of an assignment now moves to the next line when it doesn't fit, the same as a string literal. A template that prints on several lines still stays after the `=`.

<!-- prettier-ignore -->
```jsx
// Input
const stringLongEnoughToWrap = "The variable name and string are long enough that it wants a line break.";
const templateLongEnoughToWrap = `The variable name and string are long enough that it wants a line break.`;
const multilineTemplateIsUnchanged = `White space within a template literal is significant,
so a template that prints on several lines stays after the "=".`;

// Prettier stable
const stringLongEnoughToWrap =
  "The variable name and string are long enough that it wants a line break.";
const templateLongEnoughToWrap = `The variable name and string are long enough that it wants a line break.`;
const multilineTemplateIsUnchanged = `White space within a template literal is significant,
so a template that prints on several lines stays after the "=".`;

// Prettier main
const stringLongEnoughToWrap =
  "The variable name and string are long enough that it wants a line break.";
const templateLongEnoughToWrap =
  `The variable name and string are long enough that it wants a line break.`;
const multilineTemplateIsUnchanged = `White space within a template literal is significant,
so a template that prints on several lines stays after the "=".`;
```
