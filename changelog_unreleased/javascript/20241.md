#### Keep indented Markdown templates stable (#20241 by @Suwanwa)

Indented Markdown templates in object properties, call arguments and arrays retain their line break, so formatting them again produces the same result.

<!-- prettier-ignore -->
```jsx
// Input
const object = {
  value: markdown`
    # Test
  `,
};

// Prettier stable
const object = {
  value: markdown`# Test`,
};

// Prettier main
const object = {
  value: markdown`
    # Test
  `,
};
```
