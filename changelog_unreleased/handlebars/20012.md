#### Support embedded JavaScript in `<script>` (#20012 by @kovsu)

<!-- prettier-ignore -->
```hbs
{{! Input }}
<script>
  const a =    1;
  console.log( a );
</script>

{{! Prettier stable }}
<script>
  const a = 1; console.log( a );
</script>

{{! Prettier main }}
<script>
  const a = 1;
  console.log(a);
</script>
```
