#### Format `style` attribute values as CSS (#19996 by @Mohammed-Saif-Ibrahim)

Previously, Handlebars templates left `style="..."` attribute values completely untouched, unlike `language-html`, which has formatted them as embedded CSS for years. Handlebars now does the same, as long as the attribute value doesn't contain a `{{ ... }}` interpolation.

<!-- prettier-ignore -->
```hbs
{{! Input }}
<div style="color:red;    display :inline"></div>
<div style="all: initial;display: block;contain: content;text-align: center;background: linear-gradient(to left, hotpink, #FFF00F, #ccc, hsla(240, 100%, 50%, .05), transparent);max-width: 500px;margin: 0 auto;"></div>

{{! Prettier stable }}
<div style="color:red;    display :inline"></div>
<div style="all: initial;display: block;contain: content;text-align: center;background: linear-gradient(to left, hotpink, #FFF00F, #ccc, hsla(240, 100%, 50%, .05), transparent);max-width: 500px;margin: 0 auto;"></div>

{{! Prettier main }}
<div style="color: red; display: inline"></div>
<div
  style="
    all: initial;
    display: block;
    contain: content;
    text-align: center;
    background: linear-gradient(
      to left,
      hotpink,
      #fff00f,
      #ccc,
      hsla(240, 100%, 50%, 0.05),
      transparent
    );
    max-width: 500px;
    margin: 0 auto;
  "
></div>
```
