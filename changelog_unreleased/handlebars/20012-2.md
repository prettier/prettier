#### Don't format `<style lang="">` as CSS (#20012 by @kovsu)

<!-- prettier-ignore -->
```hbs
{{! Input }}
<style lang="">
  .a { color: red;
  }
</style>

{{! Prettier stable }}
<style lang="">
  .a {
    color: red;
  }
</style>

{{! Prettier main }}
<style lang="">
  .a { color: red;
  }
</style>
```
