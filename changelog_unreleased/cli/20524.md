#### Infer parsers from `env -S` shebangs (#20524 by @nyvexis1)

Prettier now recognizes `env -S` and `env --split-string=` when inferring a parser from the shebang of a script without a file extension. This allows scripts that pass arguments to their interpreter to be formatted without an explicit `--parser` option. The same inference applies to `prettier.getFileInfo()`.

For example, a script without a file extension and with the following contents previously failed with `No parser could be inferred for file`:

<!-- prettier-ignore -->
```js
#!/usr/bin/env -S node --no-warnings
console.log( 1 )
```

Prettier now formats it as:

```js
#!/usr/bin/env -S node --no-warnings
console.log(1);
```
