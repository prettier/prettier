#### Return an error exit code when checking invalid standard input (#20260 by @jum-apzn)

`--check` and `--list-different` previously printed an error but exited successfully when standard input could not be parsed, including when no parser could be inferred. They now return exit code `2`, matching the behavior for files. Unknown input is still skipped successfully with `--ignore-unknown`. Valid formatted input still exits with `0`, and input that needs formatting still exits with `1`.

```sh
printf 'function foo) {}' | prettier --parser babel --check

# Prettier stable: prints a syntax error and exits with 0
# Prettier main: prints a syntax error and exits with 2
```
