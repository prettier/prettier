#### Ignore a leading UTF-8 BOM in `.prettierrc.json` and `.prettierrc.toml` (#20113 by @Dextheking1)

Prettier now ignores a single leading UTF-8 BOM when reading `.prettierrc.json` and `.prettierrc.toml` configuration files, consistent with the JSON5 and YAML config loaders. RFC 8259 allows JSON parsers to ignore a leading BOM for interoperability.
