#### Ignore leading UTF-8 BOM in config files (#20122 by @ump45nose)

A UTF-8 BOM at the start of a config file — which editors on Windows add without asking — no longer makes the whole file fail to parse. `.prettierrc.json`, `.prettierrc.toml`, `.prettierrc.yaml` and `.prettierrc.json5` are all read the same as before, BOM or not.
