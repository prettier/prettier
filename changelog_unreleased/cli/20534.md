#### Fix `--debug-check` and `--debug-print-ast` crashing on BigInt literals (#20534 by @MFA-G)

Both flags serialized the parsed AST with `JSON.stringify()`, which throws on the native `bigint`s used for BigInt literal values.

<!-- prettier-ignore -->
```console
// Input
$ printf 'const x = 10n;\n' | prettier --debug-check --stdin-filepath bigint.js

// Prettier stable
[error] bigint.js: TypeError: Do not know how to serialize a BigInt

// Prettier main
bigint.js
```
