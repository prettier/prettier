#### Preserve Angular syntax inside `ngNonBindable` (#20066 by @splincode)

Angular treats control-flow blocks and `@let` declarations inside `ngNonBindable` as non-bindable text. Prettier now preserves their syntax instead of formatting it.

<!-- prettier-ignore -->
```html
<!-- Input -->
<span ngNonBindable>@if(foo){bar}</span>
<span ngNonBindable>@let foo=bar+baz;</span>

<!-- Prettier stable -->
<span ngNonBindable>
  @if (foo) {
    bar
  }
</span>
<span ngNonBindable>@let foo = bar + baz;</span>

<!-- Prettier main -->
<span ngNonBindable>@if(foo){bar}</span>
<span ngNonBindable>@let foo=bar+baz;</span>
```
