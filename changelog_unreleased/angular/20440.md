#### Avoid unnecessary line breaks in Angular closing tags (#20440 by @splincode)

When an Angular interpolation is followed immediately by text, Prettier could force a line break before the closing tag's `>` even if the entire line fits within `printWidth`.

<!-- prettier-ignore -->
```html
<!-- Input -->
<span>{{x}}</span>.

<!-- Prettier stable -->
<span>{{ x }}</span
>.

<!-- Prettier main -->
<span>{{ x }}</span>.
```
