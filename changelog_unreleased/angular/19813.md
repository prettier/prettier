#### Normalize spaces around `=` in multi-binding `@for` `let` clauses (#19813 by @santhiprakash)

<!-- prettier-ignore -->
```html
<!-- Input -->
@for (item of items; track item.id; let i=$index, f=$first) {
  <p>{{ item }}</p>
}

<!-- Prettier stable -->
@for (item of items; track item.id; let i=$index, f=$first) {
  <p>{{ item }}</p>
}

<!-- Prettier main -->
@for (item of items; track item.id; let i = $index, f = $first) {
  <p>{{ item }}</p>
}
```
