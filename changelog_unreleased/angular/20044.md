#### Preserve interpolations inside `ngNonBindable` (#20044 by @splincode)

Angular treats content inside `ngNonBindable` as literal text. Prettier now preserves interpolation contents in that subtree instead of formatting them as Angular expressions.

<!-- prettier-ignore -->
```html
<!-- Input -->
<span ngNonBindable>{{foo+bar}}</span>

<!-- Prettier stable -->
<span ngNonBindable>{{ foo + bar }}</span>

<!-- Prettier main -->
<span ngNonBindable>{{foo+bar}}</span>
```
