#### Preserve interpolations inside elements with `ngNonBindable` directive (#20044 by @splincode, #20115 by @fisker)

<!-- prettier-ignore -->
```html
<!-- Input -->
<span ngNonBindable>{{foo+bar}}</span>

<!-- Prettier stable -->
<span ngNonBindable>{{ foo + bar }}</span>

<!-- Prettier main -->
<span ngNonBindable>{{foo+bar}}</span>
```
