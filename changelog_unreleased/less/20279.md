#### Remove extra spaces after `[$` in indirect property lookups on variables (#20279 by @0xvikram)

<!-- prettier-ignore -->
```less
// Input
.foo {
  value: @config[$@prop-name];
}

// Prettier stable
.foo {
  value: @config[$ @prop-name];
}

// Prettier main
.foo {
  value: @config[$@prop-name];
}
```
