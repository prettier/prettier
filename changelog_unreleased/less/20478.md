#### Format Less variable values that start with `&` as selectors (#20478 by @adityajai119)

<!-- prettier-ignore -->
```less
// Input
@selector: &:not([type='file']):hover;
@compound: &>.icon+.label;

// Prettier stable
@selector: &: not([type= "file"]): hover;
@compound: &>.icon + .label;

// Prettier main
@selector: &:not([type="file"]):hover;
@compound: & > .icon + .label;
```
