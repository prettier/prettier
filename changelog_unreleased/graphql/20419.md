#### Fix range formatting of GraphQL type extensions (#20419 by @Sskift)

Formatting a selection inside a GraphQL schema or type extension now formats the enclosing extension, just as it does for definitions. Previously, selections inside extension directives could be left unchanged.

<!-- prettier-ignore -->
```graphql
# Input (select the @specifiedBy directive)
extend scalar Date @specifiedBy(url:   "x")

# Prettier stable
extend scalar Date @specifiedBy(url:   "x")

# Prettier main
extend scalar Date @specifiedBy(url: "x")
```
