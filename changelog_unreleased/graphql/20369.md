#### Format Markdown in GraphQL block descriptions (#20369 by @dagemawinegash)

GraphQL block descriptions now use Markdown formatting, including supported fenced code blocks. Ordinary string values retain their existing behavior. Use `embeddedLanguageFormatting: "off"` to disable this formatting.

<!-- prettier-ignore -->
````graphql
# Input
"""
Example response:

```json
{"name":"Ada","age":30}
```
"""
type User{name:String age:Int}

# Prettier stable
"""
Example response:

```json
{"name":"Ada","age":30}
```
"""
type User {
  name: String
  age: Int
}

# Prettier main
"""
Example response:

```json
{ "name": "Ada", "age": 30 }
```
"""
type User {
  name: String
  age: Int
}
````
