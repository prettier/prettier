#### Preserve carriage returns in GraphQL strings (#20420 by @Sskift)

Carriage returns in ordinary quoted strings are now kept escaped. Previously, formatting emitted a literal carriage return inside the string, so parsing or formatting the output again failed with an unterminated string error.

<!-- prettier-ignore -->
```graphql
# Input
{ field(value: "first\rsecond") }

# Prettier stable: the output contains a literal carriage return and cannot be parsed again.

# Prettier main
{
  field(value: "first\rsecond")
}
```
