#### Fix range formatting of nested definitions (#20421 by @Sskift)

Formatting a selection inside a variable, field, enum value, input value, or schema operation now expands to the containing document definition. Previously, Prettier tried to parse the nested definition on its own and threw a syntax error.

<!-- prettier-ignore -->
```graphql
# Input, with `field:   String` selected
type Query { field:   String }

# Prettier stable: SyntaxError: Syntax Error: Unexpected Name "field".

# Prettier main
type Query {
  field: String
}
```
