#### Fix unstable formatting of comments at the end of a list and before a selection set (#20145 by @mmilanovic4)

Two kinds of GraphQL comment were attached to a node that is printed somewhere
else, so each run moved the comment and the output only settled after two or
three runs.

A comment at the end of a variable definition or argument list now stays inside
the parentheses:

<!-- prettier-ignore -->
```graphql
# Input
query Browse(
  $search: String
  # $foo: Int
  # $bar: Int
) {
  t
}

# Prettier stable
query Browse(
  $search: String
) # $foo: Int
# $bar: Int
{
  t
}

# Prettier main
query Browse(
  $search: String
  # $foo: Int
  # $bar: Int
) {
  t
}
```

A comment between a node and the `{` of its selection set is now printed inside
the selection set immediately, instead of drifting there over several runs:

<!-- prettier-ignore -->
```graphql
# Input
{
  a # (b: C)
  {
    d
  }
}

# Prettier stable
{
  a { # (b: C)
    d
  }
}

# Prettier main
{
  a {
    # (b: C)
    d
  }
}
```
