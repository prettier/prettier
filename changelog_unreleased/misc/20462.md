#### Share `.editorconfig` reads across `resolveConfig()` calls (#20462 by @lishaduck)

Prettier now caches each parsed `.editorconfig` file and shares it with every other file under it. Previously, each call would probe from the file's directory up to the project root for every potential `.editorconfig`.

In a TypeScript monorepo using a custom formatting script, config resolution for all 786 of their files now reads the `.editorconfig` 31 times instead of 3,969, and is approximately 3× faster.
