#### Keep template literal lines of JSX in lists and blockquotes (#20331 by @b84330808)

Template literals in a JSX block inside a list item or blockquote lost the container's indentation, which changed their value on every format.

<!-- prettier-ignore -->
```mdx
{/* Input */}
1. abc
   <CodeBlock>
   {  `hello
      xxx
      `}
   </CodeBlock>

{/* Prettier stable */}
1. abc
   <CodeBlock>
     {`hello
   xxx
   `}
   </CodeBlock>

{/* Prettier main */}
1. abc
   <CodeBlock>
     {`hello
      xxx
      `}
   </CodeBlock>
```
