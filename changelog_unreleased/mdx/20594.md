#### Keep `<...>` link definition URLs on the label line (#20594 by @tJener)

With `--prose-wrap always`, a link reference definition wider than the print width would push the URL onto the next line. MDX parses a `<` at the start of a line as JSX, so a URL wrapped in `<...>` failed to compile. A URL wrapped in `<...>` now stays on the label line.

<!-- prettier-ignore -->
```mdx
{/* Input */}
[playground]: https://example.com/#g:!((g:!((g:!((h:codeEditor,i:(filename:'1')))))))

{/* Prettier stable */}
[playground]:
  <https://example.com/#g:!((g:!((g:!((h:codeEditor,i:(filename:'1')))))))>

{/* Prettier main */}
[playground]: <https://example.com/#g:!((g:!((g:!((h:codeEditor,i:(filename:'1')))))))>
```
