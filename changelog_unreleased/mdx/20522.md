#### Preserve empty nested list items (#20522 by @ydnmu)

An empty nested item immediately after a paragraph no longer turns the paragraph into a heading on a second formatting pass. The list uses `+` to avoid ambiguity with a setext heading.

<!-- prettier-ignore -->
```mdx
{/* Input */}
- foo
  +

{/* Prettier stable (first pass) */}
- foo
  -

{/* Prettier stable (second pass) */}
- ## foo

{/* Prettier main (both passes) */}
- foo
  +
```
