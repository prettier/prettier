#### Preserve SVG content with `xml:space="preserve"` (#20587 by @wozhenbang2004)

Whitespace changes inside an SVG element with `xml:space="preserve"` can move its text. Preserve the element’s inner content, including descendants, while continuing to format its opening tag. Nested `xml:space="default"` regions also retain their original formatting.

<!-- prettier-ignore -->
```html
<!-- Input -->
<svg><text xml:space="preserve" text-anchor="end" font-size="20" x="280" y="50">before  <tspan>inside</tspan>  after</text></svg>

<!-- Prettier stable -->
<svg>
  <text xml:space="preserve" text-anchor="end" font-size="20" x="280" y="50">
    before
    <tspan>inside</tspan>
    after
  </text>
</svg>

<!-- Prettier main -->
<svg>
  <text
    xml:space="preserve"
    text-anchor="end"
    font-size="20"
    x="280"
    y="50"
  >before  <tspan>inside</tspan>  after</text>
</svg>
```
