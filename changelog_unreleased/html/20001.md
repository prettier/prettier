#### Avoid adding blank lines to unformatted interpolations (#20001 by @vzer200)

When `embeddedLanguageFormatting` is `"off"`, Angular and Vue interpolations with a trailing newline no longer gain an extra blank line on each formatting pass when followed immediately by text.

<!-- prettier-ignore -->
```html
<!-- Input (--parser angular --embedded-language-formatting off) -->
<div>
  ({{ a
  }})
</div>

<!-- Prettier stable -->
<div>
  ({{ a

  }})
</div>

<!-- Prettier main -->
<div>
  ({{ a
  }})
</div>
```
