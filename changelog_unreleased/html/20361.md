#### Preserve whitespace in script data blocks (#20361 by @splincode)

Prettier preserves the contents of script data blocks with no embedded formatter and formats Markdown script contents without inheriting HTML indentation.

<!-- prettier-ignore -->
```html
<!-- Input -->
<div>
  <script type="text/plain">
first line
  second line
  </script>
</div>

<!-- Prettier stable -->
<div>
  <script type="text/plain">
    first line
    second line
  </script>
</div>

<!-- Prettier main -->
<div>
  <script type="text/plain">
first line
  second line
  </script>
</div>
```
