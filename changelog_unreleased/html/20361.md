#### Preserve whitespace in script elements with a type attribute (#20361 by @splincode)

Prettier preserves the contents of `<script type="…">` elements when there is no embedded formatter. When an embedded formatter is available, Prettier formats the contents without adding the surrounding HTML indentation.

<!-- prettier-ignore -->
```html
<!-- Input -->
<div>
  <script type="text/plain">
first line
  second line
  </script>
</div>

<!-- Prettier stable -->
<div>
  <script type="text/plain">
    first line
    second line
  </script>
</div>

<!-- Prettier main -->
<div>
  <script type="text/plain">
first line
  second line
  </script>
</div>
```
