#### Preserve tag names and delimiters in ignored HTML (#20578 by @porada)

Prettier could also drop the closing quote from an ignored `<img>` attribute or lowercase only the opening tag of an ignored `<SPAN>`. Both cases produced HTML that Prettier couldn’t format a second time.

<!-- prettier-ignore -->
```html
<!-- Input -->
<span><!-- prettier-ignore --><br></span>

<!-- Prettier stable -->
<span><!-- prettier-ignore --><br>/></span>

<!-- Prettier main -->
<span><!-- prettier-ignore --><br></span>
```
