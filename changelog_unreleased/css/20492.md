#### Count trailing text when filling lines (#20492 by @manav4u)

A filled line now accounts for text that follows its final item, such as the semicolon at the end of a CSS declaration. This also affects filled text in HTML and Handlebars.

<!-- prettier-ignore -->
```css
/* Input */
.test {
  margin: $really-long-variable-name $another-really-long-name $a-third-long-nam;
}

/* Prettier stable */
.test {
  margin: $really-long-variable-name $another-really-long-name $a-third-long-nam;
}

/* Prettier main */
.test {
  margin: $really-long-variable-name $another-really-long-name
    $a-third-long-nam;
}
```
