#### Preserve custom property calls inside nested functions (#20548 by @pei711)

<!-- prettier-ignore -->
```css
/* Input */
a {
  width: min(calc(5 * var(--100px)), 80%);
}

/* Prettier stable */
a {
  width: min(calc(5 * var(--100px,)), 80%);
}

/* Prettier main */
a {
  width: min(calc(5 * var(--100px)), 80%);
}
```
