#### Fix trailing comma added to `var()` with a custom property name starting with a digit (#20549 by @MIbtehajNasar)

<!-- prettier-ignore -->
```css
/* Input */
a {
  width: min(calc(5 * var(--100px)), 80%);
}

/* Prettier stable */
a {
  width: min(calc(5 * var(--100px,)), 80%);
}

/* Prettier main */
a {
  width: min(calc(5 * var(--100px)), 80%);
}
```
