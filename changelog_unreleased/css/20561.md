#### Keep semicolon after nested blocks in custom property values (#20561 by @MIbtehajNasar)

<!-- prettier-ignore -->
```css
/* Input */
.test {
  --data: {
    nested: {
      value: red;
    };
    another: blue;
  };
}

/* Prettier stable */
.test {
  --data: {
    nested: {
      value: red;
    }
    another: blue;
  };
}

/* Prettier main */
.test {
  --data: {
    nested: {
      value: red;
    };
    another: blue;
  };
}
```
