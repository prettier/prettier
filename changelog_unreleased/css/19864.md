#### Fix overrun of CSS comma-separated value after a block comment followed by a negative value (#18311 by @lurantys)

A block comment followed by a value starting with a unary minus (e.g. `-1px`) was merged with the value into a single unbreakable unit, so the value stayed on the same line as the comment and overran `printWidth`.

<!-- prettier-ignore -->
```css
/* Input */
.foo {
  box-shadow:
    2px 2px 4px gray,
    /* long long long long long long long long long long long long comment */ -1px -1px 2px lightgray;
}

/* Prettier stable */
.foo {
  box-shadow:
    2px 2px 4px gray,
    /* long long long long long long long long long long long long comment */ -1px -1px
      2px lightgray;
}

/* Prettier main */
.foo {
  box-shadow:
    2px 2px 4px gray,
    /* long long long long long long long long long long long long comment */
    -1px -1px 2px lightgray;
}
```
