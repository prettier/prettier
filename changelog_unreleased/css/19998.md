#### Preserve trailing commas in custom properties (#19998 by @vzer200)

<!-- prettier-ignore -->
```css
/* Input */
.foo { --interpolation-method: in oklab,; }

/* Prettier stable */
.foo {
  --interpolation-method: in oklab;
}

/* Prettier main */
.foo {
  --interpolation-method: in oklab,;
}
```
