#### Preserve signs on numeric color components (#20045 by @pentaoa)

Keep a sign attached to its color component, so formatting does not turn valid CSS into an invalid declaration. This applies to relative colors and absolute `color()` components; nested math expressions keep their operator spacing.

<!-- prettier-ignore -->
```css
/* Input */
a { color: oklch(from red l c +130); }

/* Prettier stable */
a {
  color: oklch(from red l c + 130);
}

/* Prettier main */
a {
  color: oklch(from red l c +130);
}
```
