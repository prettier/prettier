#### Preserve spaces between url modifiers in `url()` (#20622 by @kovsu)

<!-- prettier-ignore -->
```css
/* Input */
a {
  background-image: url("image.png" cross-origin(anonymous));
}

/* Prettier stable */
a {
  background-image: url("image.png"cross-origin(anonymous));
}

/* Prettier main */
a {
  background-image: url("image.png" cross-origin(anonymous));
}
```
