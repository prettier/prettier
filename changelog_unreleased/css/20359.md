#### Fix crash on an escaped parenthesis in `url()` (#20359 by @Huang-404-Q)

Previously, an escaped `)` in an unquoted `url()` made Prettier throw `Unbalanced parenthesis`.

<!-- prettier-ignore -->
```css
/* Input */
a{background:url(foo\)bar)}

/* Prettier stable */
Error: Unbalanced parenthesis

/* Prettier main */
a {
  background: url(foo\)bar);
}
```
