#### Print import attributes in ambient module declarations (#20626 by @abdul-karim-mia)

Adds ESTree printer and visitor-key support so custom parsers that produce `TSModuleDeclaration.attributes` do not drop import attributes when formatting ambient module declarations.

<!-- prettier-ignore -->
```ts
// Input
declare module "*.txt" with { type: "text" } {}

// Prettier stable
declare module "*.txt" {}

// Prettier main
declare module "*.txt" with { type: "text" } {}
```
