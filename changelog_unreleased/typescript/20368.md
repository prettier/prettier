#### Keep comments after `in` stable in mapped types (#20368 by @kropdx)

Comments between `in` and the constraint of a TypeScript mapped type now stay in place when formatting repeatedly.

<!-- prettier-ignore -->
```ts
// Input
type a= {
    [
      A in
      /* comment */
      B
    ]: C  |  D
  }

// Prettier stable (first format)
type a = {
  [
    A in /* comment */
    B
  ]: C | D;
};

// Prettier stable (second format)
type a = {
  [A /* comment */ in B]: C | D;
};

// Prettier main (first and second format)
type a = {
  [
    A in
      /* comment */
      B
  ]: C | D;
};
```
