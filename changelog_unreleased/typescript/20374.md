#### Stabilize comments before generic function type parameters (#20374 by @Arham-Begani)

Comments between a named function and its type parameters now remain stable across formatting passes in TypeScript and Flow.

<!-- prettier-ignore -->
```ts
// Input
declare function a
  /* comment */
  <T>(value: T): T;

// Prettier 3.9.9, first pass
declare function a/* comment */
<T>(value: T): T;

// Prettier 3.9.9, second pass
declare function a /* comment */<T>(value: T): T;

// Prettier main
declare function a /* comment */
<T>(value: T): T;
```
