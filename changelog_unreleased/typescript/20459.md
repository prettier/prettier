#### Keep parentheses around `<` comparison on the left side of `>` (#20459 by @lazerg)

<!-- prettier-ignore -->
```tsx
// Input
(a < b) > (c ? c : c);
(a < b) > `${c}`;

// Prettier stable
a < b > (c ? c : c);
a < b > `${c}`;

// Prettier main
(a < b) > (c ? c : c);
(a < b) > `${c}`;
```

_This also applies to JavaScript and Flow._
