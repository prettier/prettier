#### Fix duplicate statement after top-level await (#20098 by @ryux1)

TypeScript's top-level-await reparse can return the final statement twice in
the parsed AST. Prettier now removes the duplicate instead of printing it again
on every formatting pass.

<!-- prettier-ignore -->
```tsx
// Input
await { then() {} };

await getPromise;

// Prettier stable
await { then() {} };

await getPromise;
await getPromise;

// Prettier main
await { then() {} };

await getPromise;
```
