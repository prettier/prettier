#### Keep ordinary line comments before TypeScript enum and namespace bodies stable (#20193 by @Rober1208)

Ordinary line comments between a declaration name and its opening brace now print on their own line inside the body on the first format, without moving again on the second format.

<!-- prettier-ignore -->
```tsx
// Input
enum F // comment
{ A }

namespace N // comment
{ a; }

// Prettier stable
enum F { // comment
  A,
}

namespace N { // comment
  a;
}

// Prettier main
enum F {
  // comment
  A,
}

namespace N {
  // comment
  a;
}
```
