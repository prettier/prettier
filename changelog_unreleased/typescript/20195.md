#### Preserve comments before empty constructor type parameters (#20195 by @Rober1208)

Keep comments after `new` before the parentheses in non-generic empty TypeScript constructor types and construct signatures.

<!-- prettier-ignore -->
```ts
// Input
type Constructor = new /* before */ (/* inside */) /* after */ => string;

// Prettier stable
type Constructor = new (/* inside */) /* before */ /* after */ => string;

// Prettier main
type Constructor = new /* before */ (/* inside */) /* after */ => string;
```
