#### Preserve parentheses in mapped type constraints (#20254 by @Suwanwa)

Removing these parentheses changes whether TypeScript preserves optional and readonly modifiers from the source type.

<!-- prettier-ignore -->
```ts
// Input
type BooleanValues = { [Key in (keyof MyObject)]: boolean };

// Prettier stable
type BooleanValues = { [Key in keyof MyObject]: boolean };

// Prettier main
type BooleanValues = { [Key in (keyof MyObject)]: boolean };
```
