#### Fix unstable comments before superclass type arguments (#20589 by @smg99)

Line comments between a superclass and its type arguments now produce stable output in TypeScript and Flow.

<!-- prettier-ignore -->
```ts
// Input
class A extends B
// comment
<T> {}

// Prettier stable
class A extends B// comment
<T> {}

// Prettier main
class A extends B<T> {}
// comment
```
