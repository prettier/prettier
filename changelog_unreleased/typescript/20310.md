#### Fix unstable comment between enum or namespace name and `{` (#20310 by @DeviousCardi)

This also fixes Flow enums.

<!-- prettier-ignore -->
```ts
// Input
enum F // comment
{ A }

namespace N // comment
{ a; }

// Prettier stable (first format)
enum F { // comment
  A,
}

namespace N { // comment
  a;
}

// Prettier main
enum F {
  // comment
  A,
}

namespace N {
  // comment
  a;
}
```
