#### Keep comments before exported decorators stable (#20175 by @charan-rathore)

Prettier no longer adds another blank line on each formatting pass when a comment appears between `export` and a decorator.

<!-- prettier-ignore -->
```tsx
// Input
export /* c */ @dec class A {}

// Prettier stable
export /* c */
@dec
class A {}

// Prettier main
export /* c */ @dec class A {}
```
