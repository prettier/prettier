#### Keep comments between the heritage clauses of decorated classes in place (#20494 by @adityajai119)

<!-- prettier-ignore -->
```ts
// Input
@decorator
class Foo extends Bar
  // comment
  implements Baz {}

// Prettier stable
@decorator
// comment
class Foo extends Bar implements Baz {}

// Prettier main
@decorator
class Foo
  extends Bar
  // comment
  implements Baz {}
```
