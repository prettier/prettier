#### Reject misplaced `export` modifiers on TypeScript classes (#20190 by @Alex0AI)

Prettier now reports a syntax error when `export` follows `abstract` or `declare` on a TypeScript class. Previously, the TypeScript parser recovered from this invalid modifier order but omitted `export` from its syntax tree, so formatting silently removed the class's export.

```ts
// Input (invalid TypeScript)
abstract export class A {}

// Prettier stable
abstract class A {}

// Prettier main
// SyntaxError: 'export' modifier must precede other modifiers. (1:10)
```
