#### Fix comments between class superclasses and type arguments (#20189 by @git-create-devben)

Line comments between a superclass and its type arguments now format consistently.
Line-scoped directives stay before the type arguments so they keep their effect.

<!-- prettier-ignore -->
```tsx
// Input
class A extends B
// comment
<T> {}

// Prettier stable
class A extends B// comment
<T> {}

// Prettier main
class A extends B<T> {} // comment
```
