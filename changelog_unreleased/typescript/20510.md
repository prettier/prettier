#### Preserve bodyless declaration boundaries in no-semi mode (#20510 by @shenxi200-eng)

Preserve the semicolon between a bodyless TypeScript module or function declaration and a following independent block, even with `semi: false`. Without it, the block can become the declaration's body when the output is parsed again. Ordinary overloads and declarations without a following block keep their existing formatting.

This also applies to ignored declarations and declaration-only range formatting.

<!-- prettier-ignore -->
```ts
// Input
declare module "x";
{ console.log("live"); }

// Prettier stable (--no-semi)
declare module "x"
{
  console.log("live")
}

// Prettier main (--no-semi)
declare module "x";
{
  console.log("live")
}
```
