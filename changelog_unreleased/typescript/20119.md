#### Keep a comment written before an optional parameter marker (#20119 by @wfatih)

A comment between a parameter name and its `?` had no node to attach to when the parameter carried no type annotation, so Prettier refused to format the file. The same applies to Flow.

<!-- prettier-ignore -->
```tsx
// Input
function untyped(a/*c*/?) {}

// Prettier stable
[error] Comment "c" was not printed. Please report this error!

// Prettier main
function untyped(a? /*c*/) {}
```
