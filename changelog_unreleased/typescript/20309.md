#### Fix range formatting inside type parameter lists (#20309 by @sansynx)

Selecting text inside a TypeScript type parameter list now formats the enclosing declaration instead of trying to parse the parameter list on its own.

With `--parser typescript --range-start 9 --range-end 10`:

<!-- prettier-ignore -->
```tsx
// Input
type Box<T> = {value:T};

// Prettier stable
// SyntaxError: Expression expected. (1:4)
// > 1 | <T>
//     |    ^

// Prettier main
type Box<T> = { value: T };
```
