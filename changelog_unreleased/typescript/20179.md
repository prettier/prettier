#### Keep comments before parameter property modifiers (#20179 by @charan-rathore)

A comment in a parameter property's default value no longer moves between the access modifier and the parameter name. The output remains valid TypeScript when formatted again.

<!-- prettier-ignore -->
```tsx
// Input
class A {
  constructor(private a = (
    // c
    1
  )) {}
}

// Prettier stable
class A {
  constructor(
    private // c
    a = 1,
  ) {}
}

// Prettier main
class A {
  constructor(
    // c
    private a = 1,
  ) {}
}
```
