#### Add parentheses to `TSInstantiationExpression` in unary expressions and type assertions (#20454 by @vidigoat)

<!-- prettier-ignore -->
```tsx
// Input
x = (typeof make<T>) + y;
x = (<any>make<T>) - y;

// Prettier stable
x = typeof make<T> + y;
x = <any>make<T> - y;

// Prettier main
x = typeof (make<T>) + y;
x = <any>(make<T>) - y;
```
