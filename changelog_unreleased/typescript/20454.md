#### Add parentheses around unary expressions and type assertions that end with a `TSInstantiationExpression` (#20454 by @vidigoat)

<!-- prettier-ignore -->
```tsx
// Input
x = (typeof make<T>) + y;
x = (<any>make<T>) - y;

// Prettier stable
x = typeof make<T> + y;
x = <any>make<T> - y;

// Prettier main
x = (typeof make<T>) + y;
x = (<any>make<T>) - y;
```
