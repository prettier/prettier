#### Preserve leading semicolons in ignored TypeScript statements (#20172 by @le700)

<!-- prettier-ignore -->
```tsx
// Input (--no-semi)
log()
// prettier-ignore
;(new  Widget).run()

// Prettier stable
log()
// prettier-ignore
(new  Widget).run()

// Prettier stable (Second format)
log()(
  // prettier-ignore
  new  Widget,
).run()

// Prettier main
log()
// prettier-ignore
;(new  Widget).run()
```
