#### Avoid unwanted line breaks from empty line suffixes (#20239 by @Suwanwa)

An empty `lineSuffix` no longer forces a surrounding group to break when followed by `lineSuffixBoundary`. This also applies to empty arrays and indented empty Docs. Nonempty suffixes and cursor markers keep their existing behavior.

<!-- prettier-ignore -->
```js
// Doc passed to printDocToString, with printWidth: 80
group(["a", lineSuffix(""), lineSuffixBoundary, line, "b"]);

// Prettier stable
"a\n\nb";

// Prettier main
"a b";
```
