#### Preserve cursor positions for empty input and before a BOM (#20525 by @nyvexis1)

`formatWithCursor()` now returns a valid cursor position when formatting empty input or removing all whitespace. Previously, these cases returned `-1`, even when cursor tracking was requested. A cursor before a byte order mark (BOM) now stays at offset `0` instead of losing its position. Cursors after a preserved BOM stay after it.

```js
await prettier.formatWithCursor(" \t\n", {
  parser: "babel",
  cursorOffset: 2,
});

// Prettier stable
// { formatted: "", cursorOffset: -1 }

// Prettier main
// { formatted: "", cursorOffset: 0 }
```
