#### Reload module config files after `clearConfigCache()` (#20537 by @lazerg)

`prettier.clearConfigCache()` and `resolveConfig(file, { useCache: false })` now pick up changes to configuration files that are modules (`.js`, `.mjs`, `.cjs`, `.ts`, etc.) in a long-running process.

```js
// prettier.config.mjs: export default { tabWidth: 3 };
await prettier.resolveConfig("file.js"); // { tabWidth: 3 }

// prettier.config.mjs changed to: export default { tabWidth: 5 };
await prettier.clearConfigCache();

// Prettier stable
await prettier.resolveConfig("file.js"); // { tabWidth: 3 }

// Prettier main
await prettier.resolveConfig("file.js"); // { tabWidth: 5 }
```
