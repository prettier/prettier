#### Reload module config files after `clearConfigCache()` (#20537 by @lazerg)

`prettier.clearConfigCache()` and `resolveConfig(file, { useCache: false })` now pick up changes to module configuration files (`prettier.config.js`, `.prettierrc.mjs`, `.prettierrc.cjs`, `prettier.config.ts`, etc.) in a long-running process.

```js
fs.writeFileSync("prettier.config.mjs", "export default {tabWidth: 2};");
await prettier.resolveConfig("file.js");
await prettier.clearConfigCache();
fs.writeFileSync("prettier.config.mjs", "export default {tabWidth: 4};");
console.log(await prettier.resolveConfig("file.js"));

// Prettier stable
// => { tabWidth: 2 }

// Prettier main
// => { tabWidth: 4 }
```
