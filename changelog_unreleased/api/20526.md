#### Preserve cursor positions when inserting a pragma (#20526 by @nyvexis1)

`formatWithCursor()` now accounts for text added or rewritten by `insertPragma`, keeping the cursor in the original source. Previously, inserting a pragma could move the cursor into the new comment.

```js
await prettier.formatWithCursor("const foo=1", {
  parser: "babel",
  cursorOffset: 8,
  insertPragma: true,
});

// Prettier stable
// { formatted: "/** @format */\n\nconst foo = 1;\n", cursorOffset: 8 }

// Prettier main
// { formatted: "/** @format */\n\nconst foo = 1;\n", cursorOffset: 24 }
```
