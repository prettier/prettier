#### Preserve exported configuration objects when removing `$schema` (#20523 by @nyvexis1)

Prettier now removes `$schema` from a copy of the loaded configuration instead of modifying the object exported by a JavaScript configuration file. This allows frozen configuration objects to load successfully and preserves `$schema` for other consumers of a shared configuration.

```js
// prettier.config.mjs
export default Object.freeze({
  $schema: "https://www.schemastore.org/prettierrc",
  semi: false,
});
```

Previously, resolving this configuration threw `TypeError: Cannot delete property '$schema' of #<Object>`. It now resolves to `{ semi: false }`.
