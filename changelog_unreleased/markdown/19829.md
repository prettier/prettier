#### Preserve lazy setext-like lines in Markdown (#19829 by @justinjd00)

A line composed of only `=` or `-` written as a "lazy" blockquote (or list) continuation line was pulled into the container and escaped. It stays a lazy continuation line now, preserving the original text.

<!-- prettier-ignore -->
```markdown
<!-- Input -->
> Foo
===

<!-- Prettier stable -->
> Foo
> \===

<!-- Prettier main -->
> Foo
===
```
