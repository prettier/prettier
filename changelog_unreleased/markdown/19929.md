#### Escape indented table delimiter rows (#19929 by @fahadhewad)

A table delimiter row that is indented by four spaces or more is part of a paragraph, not of a table. Prettier removed that indentation without escaping the row, so the paragraph was parsed as a table the next time the file was formatted, and formatting was not idempotent. Prettier now escapes such rows to keep them out of a table:

<!-- prettier-ignore -->
```markdown
<!-- Input -->
| a | b |
        | - | - |
| 1 | 2 |

<!-- Prettier stable -->
| a | b |
| - | - |
| 1 | 2 |

<!-- Prettier main -->
| a | b |
\| - | - |
| 1 | 2 |
```
