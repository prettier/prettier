#### Keep inline HTML that starts a block out of the line start (#20106 by @Maher-Reven)

Inline HTML matching one of CommonMark's [HTML block start conditions](https://spec.commonmark.org/0.31.2/#html-blocks) 1-6 ends the paragraph it belongs to as soon as it begins a line. With `proseWrap: "always"`, wrapping could move such a node to the start of a line, splitting one paragraph into several blocks. Prettier no longer breaks the line before it. Condition 7 is unaffected, since it cannot interrupt a paragraph.

<!-- prettier-ignore -->
```markdown
<!-- Input (--prose-wrap always --print-width 20) -->
alpha <!-- retained comment --> beta

<!-- Prettier stable -->
alpha
<!-- retained comment -->
beta

<!-- Prettier main -->
alpha <!-- retained comment -->
beta
```
