#### Count escaped backticks when fencing a code block in a JS template (#19908 by @Kjubikstronk)

A code block nested inside another one in a `md` template is fenced with `~` when printed, so the outer fence has to be longer than the run of tildes the nested fence ends up occupying.

<!-- prettier-ignore -->
````jsx
// Input
md`
\`\`\`js
markdown\`
    \\\`\\\`\\\`js
    console.log('hi');
    \\\`\\\`\\\`
\`
\`\`\`
`;

// Prettier stable (first format)
md`
~~~js
markdown\`
  ~~~js
  console.log("hi");
  ~~~
\`;
~~~
`;

// Prettier main
md`
~~~~js
markdown\`
  ~~~js
  console.log("hi");
  ~~~
\`;
~~~~
`;
````
