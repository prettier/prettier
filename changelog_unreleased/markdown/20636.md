#### Keep balanced parentheses in Markdown link destinations (#20636 by @NakulKhanna2001)

Prettier now prints inline links and images with the same rules it uses for reference definitions. Destinations with up to three levels of balanced parentheses can be printed without angle brackets.

<!-- prettier-ignore -->
```md
<!-- Input -->
[report](report_(2026))

<!-- Prettier stable -->
[report](<report_(2026)>)

<!-- Prettier main -->
[report](report_(2026))
```
