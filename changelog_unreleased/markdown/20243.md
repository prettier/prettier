#### Preserve the blank line between an HTML block and a nested list in a list item (#17738 by @devanshranjan10)

Without the blank line, the nested list became part of the HTML block, so it was no longer rendered as a list.

<!-- prettier-ignore -->
```md
<!-- Input -->
- Some text

  <details>
    <summary>Summary</summary>

    - Lorem
    - ipsum
  </details>

<!-- Prettier stable -->
- Some text

  <details>
    <summary>Summary</summary>
  - Lorem
  - ipsum

  </details>

<!-- Prettier main -->
- Some text

  <details>
    <summary>Summary</summary>

  - Lorem
  - ipsum

  </details>
```
