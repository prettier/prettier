#### Keep `*` for emphasis starting with strong inside strong (#20056 by @Minouccc)

Underscore-styled emphasis that starts with a `strong` child no longer loses its emphasis on a second format. Previously `**a ***b*** c**` was printed as `**a _**b**_ c**`, which re-parses differently (the inner `**` pairs with the outer strong delimiters), so formatting again produced `**a _**b**\_ c**`.

<!-- prettier-ignore -->
```markdown
<!-- Input -->
**a ***b*** c**

<!-- Prettier stable -->
**a _**b**_ c**

<!-- Prettier main -->
**a ***b*** c**
```
