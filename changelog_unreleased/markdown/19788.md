#### Fix extra blank lines around HTML comments between Markdown list items (#19788 by @santhiprakash)

Prettier 3.9.0+ was inserting blank lines around HTML comments that sit between Markdown list items, splitting the list. This is now fixed.

<!-- prettier-ignore -->
```markdown
<!-- Input -->
- Head
<!-- divider -->
- Body
<!-- divider -->
- Foot

<!-- Prettier stable -->
- Head

<!-- divider -->

- Body

<!-- divider -->

- Foot

<!-- Prettier main -->
- Head
<!-- divider -->
- Body
<!-- divider -->
- Foot
```
