#### Escape indented pseudo table delimiter rows (#19848 by @lazerg)

A delimiter row indented by four or more spaces does not start a table. Prettier dropped that indentation when it printed the paragraph, so the output parsed as a table on the next run. Such a row is now escaped.

<!-- prettier-ignore -->
```markdown
<!-- Input -->
| x | y |
    |---|---|

<!-- Prettier stable -->
| x | y |
|---|---|

<!-- Prettier main -->
| x | y |
\|---|---|
```
