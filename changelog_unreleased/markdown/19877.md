#### Keep an indented table delimiter row from becoming a table (#19877 by @Kjubikstronk)

A delimiter row indented by four or more spaces is not part of a table, but it lost its indentation when printed and the next run formatted it as one.

<!-- prettier-ignore -->
```md
<!-- Input -->
| x | y |
    |---|---|

<!-- Prettier stable -->
| x | y |
|---|---|

<!-- Prettier main -->
| x | y |
\|---|---|
```
