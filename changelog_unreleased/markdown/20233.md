#### Escape indented pseudo table delimiter rows (#20233 by @Detoy)

A table delimiter row indented by four or more spaces is not part of a table, so the lines stay a paragraph. Prettier removed that indentation without escaping the row, which turned the paragraph into a table on the next format. Such rows are now escaped.

<!-- prettier-ignore -->
```markdown
<!-- Input -->
| x | y |
    |---|---|

<!-- Prettier stable (First format) -->
| x | y |
|---|---|

<!-- Prettier stable (Second format) -->
| x   | y   |
| --- | --- |

<!-- Prettier main -->
| x | y |
\|---|---|
```
