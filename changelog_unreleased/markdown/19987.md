#### Fix HTML block indentation drift in markdown list items (#19987 by @lazerg)

Raw HTML nested in a list item kept the indentation beyond the marker width baked into its parsed value, and the printer's own list-item alignment added another layer on top of it. Parsing the file again picked up that extra indentation, so the block drifted further right on every pass.

<!-- prettier-ignore -->
```markdown
<!-- Input -->
1. Enable images:

    <p align="center">
      <img alt="example">
    </p>

<!-- Prettier stable -->
1. Enable images:

     <p align="center">
       <img alt="example">
     </p>

<!-- Prettier main -->
1. Enable images:

    <p align="center">
      <img alt="example">
    </p>
```
