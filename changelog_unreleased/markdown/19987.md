#### Fix HTML block indentation drift in markdown list items (#19987 by @lazerg)

Raw HTML nested in a list item drifted one column further right on every format pass with `--tab-width 4`, never settling down.

<!-- prettier-ignore -->
```markdown
<!-- tabWidth: 4 -->
<!-- Input -->
1. Enable images:

    <p align="center">
      <img alt="example">
    </p>

<!-- Prettier stable -->
1. Enable images:

     <p align="center">
       <img alt="example">
     </p>

<!-- Prettier main -->
1. Enable images:

    <p align="center">
      <img alt="example">
    </p>
```
