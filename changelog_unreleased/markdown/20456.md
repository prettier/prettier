#### Preserve indented table delimiter rows as paragraph text (#20456 by @djha11)

Indents of four or more spaces can make a table-looking delimiter row part of a Markdown paragraph. Keep it from becoming a table after formatting normalizes the indentation.

<!-- prettier-ignore -->
```md
<!-- Input -->
| a | b |
    |---|---|
| c | d |

<!-- Prettier -->
| a | b |  
    \|---|---|  
| c | d |
```
