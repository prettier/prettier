#### Fix regression: `{{...}}` inline Liquid expressions should not interrupt paragraphs (#20083 by @nikolas-sapa)

`{{...}}` inline Liquid expressions at the start of a line no longer incorrectly break out of the current paragraph, which was causing unwanted blank lines to be inserted between paragraphs separated by `{{...}}` on new lines. Regression introduced in #19838.

<!-- prettier-ignore -->
```markdown
<!-- Input -->
**ASCII** (_American Standard Code for Information Interchange_) is a {{glossary("character encoding")}} standard using 7-bit to represent 128
{{glossary("character", "characters")}} used by computers and other devices.

<!-- Prettier 3.9.7 (broken) -->
**ASCII** (_American Standard Code for Information Interchange_) is a {{glossary("character encoding")}} standard using 7-bit to represent 128

{{glossary("character", "characters")}} used by computers and other devices.

<!-- Prettier main (fixed) -->
**ASCII** (_American Standard Code for Information Interchange_) is a {{glossary("character encoding")}} standard using 7-bit to represent 128
{{glossary("character", "characters")}} used by computers and other devices.
```
