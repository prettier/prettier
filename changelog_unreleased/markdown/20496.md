#### Preserve ignored code fence contents inside JSX (#20496 by @danliu0877-beep)

In the MDX parser upgrade (#18533), formatting an ignored code fence inside JSX indented only its opening line. Parsing the result then stripped that indentation from the code contents. Closed ignored fences now preserve their contents while adopting the surrounding JSX, list, or blockquote indentation.

Input:

<!-- prettier-ignore -->
````mdx
<div>

{/* prettier-ignore */}
```js
function f() {
  return 1;
}
```

</div>
````

MDX branch before this change:

<!-- prettier-ignore -->
````mdx
<div>
  {/* prettier-ignore */}
  ```js
function f() {
  return 1;
}
```
</div>
````

With this change:

<!-- prettier-ignore -->
````mdx
<div>
  {/* prettier-ignore */}
  ```js
  function f() {
    return 1;
  }
  ```
</div>
````
