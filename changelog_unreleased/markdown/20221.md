#### Keep link reference labels as written (#20221 by @kevin9327)

Character references and backslash escapes in reference labels were decoded when printing, which could disconnect a definition from its shortcut or collapsed references.

<!-- prettier-ignore -->
```md
<!-- Input -->
See [RFC&nbsp;9111][].

[RFC&nbsp;9111]: https://www.rfc-editor.org/rfc/rfc9111.html

<!-- Prettier stable -->
See [RFC&nbsp;9111][].

[RFC 9111]: https://www.rfc-editor.org/rfc/rfc9111.html

<!-- Prettier main -->
See [RFC&nbsp;9111][].

[RFC&nbsp;9111]: https://www.rfc-editor.org/rfc/rfc9111.html
```
