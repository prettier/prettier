#### Don't turn a line after a hard line break into a setext heading (#19776 by @Hydr0gen19)

A line that only contains `=` or `-` characters is not a setext heading underline when it follows a hard line break. Prettier now escapes it so that it stays paragraph text.

<!-- prettier-ignore -->
```markdown
<!-- Input -->
> Foo\
===

<!-- Prettier stable -->
> Foo\
> ===

<!-- Prettier main -->
> Foo\
> \===
```
