#### Prevent wrapped prose from starting a fenced code block (#20288 by @devanshranjan10)

With `--prose-wrap always`, a line break could be placed right before a run of three or more backticks or tildes, which turned the rest of the document into a code block.

<!-- prettier-ignore -->
```md
<!-- Input -->
To show a snippet without syntax highlighting, start the line with three tildes ~~~ and close it the same way.

See the next section.

<!-- Prettier stable (--prose-wrap always) -->
To show a snippet without syntax highlighting, start the line with three tildes
~~~ and close it the same way.

See the next section.

<!-- Prettier main (--prose-wrap always) -->
To show a snippet without syntax highlighting, start the line with three
tildes ~~~ and close it the same way.

See the next section.
```
