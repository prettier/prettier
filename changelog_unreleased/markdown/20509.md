#### Preserve multiline inline code indentation in containers (#20509 by @butrico31)

With `proseWrap: "preserve"`, multiline inline code inside Markdown lists could lose indentation on each formatting pass, changing the code span's contents. Continuation lines now retain their container indentation, including blockquote markers.

<!-- prettier-ignore -->
```md
<!-- Input -->
- a `x/
      y` z

<!-- Prettier stable -->
- a `x/
    y` z

<!-- Prettier main -->
- a `x/
      y` z
```
