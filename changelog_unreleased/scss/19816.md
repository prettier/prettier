#### Keep trailing line comment on value line after comma (#19816 by @santhiprakash)

This also affects Less lists/maps with the same trailing `//` comment pattern.

<!-- prettier-ignore -->
```scss
// Input
@use "library" with (
  $size-1: 1rem,
  $size-2: 2.5rem, // Big
  $size-3: 3rem
);

// Prettier stable
@use "library" with (
  $size-1: 1rem,
  $size-2: 2.5rem,
  // Big
  $size-3: 3rem
);

// Prettier main
@use "library" with (
  $size-1: 1rem,
  $size-2: 2.5rem, // Big
  $size-3: 3rem
);
```
