#### Format a map entry after a comment like any other entry (#20424 by @vibbix)

<!-- prettier-ignore -->
```scss
// Input
$map: (
  "a": (1, 2),
  // comment
  "b": (3, 4),
);

// Prettier stable
$map: (
  "a": (
    1,
    2,
  ),
  // comment
  "b": (
      3,
      4,
    ),
);

// Prettier main
$map: (
  "a": (
    1,
    2,
  ),
  // comment
  "b": (
    3,
    4,
  ),
);
```
