#### Fix trailing comma position before multiple line comments in maps (#20547 by @peralva)

<!-- prettier-ignore -->
```scss
// Input
$my-map: (

  // Comment
);

  "foo": 1,
  "bar": 2 // Comment
  , // Comment
);

$my-map: (
  "foo": 1,
  "bar": 2, // Comment
  // Comment
);
```
