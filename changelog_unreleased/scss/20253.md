#### Insert SCSS trailing commas before trailing line comments (#20253 by @Suwanwa)

<!-- prettier-ignore -->
```scss
// Input
$map: (
  "foo": 1,
  "bar": 2 // First comment
  // Second comment
);

// Prettier stable
$map: (
  "foo": 1,
  "bar": 2 // First comment
  , // Second comment
);

// Prettier main
$map: (
  "foo": 1,
  "bar": 2, // First comment
  // Second comment
);
```
