#### Fix `//` comment being swallowed in selector lists with empty attribute values (#20303 by @fixfon)

The same fix applies to Less.

<!-- prettier-ignore -->
```scss
// Input
a[href=""], // comment
foo a[href=""] {
  color: red;
}

// Prettier stable
a[href=""],
// comment foo a[href=""] {
  color: red;
}

// Prettier main
a[href=""], // comment
foo a[href=""] {
  color: red;
}
```
