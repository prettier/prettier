#### Fix extra blank line after folded block scalar with `proseWrap: "never"` (#20477 by @Sun-Wukhan)

When a folded block scalar was followed by a blank line and the next mapping key, Prettier added an extra blank line if `proseWrap` was set to `"never"`. The blank line is now kept as-is.

```yaml
# Input
jobs:
  check:
    if: >-
      github.event_name != 'pull_request'

    steps:
      - uses: actions/checkout@v7

# Prettier stable
jobs:
  check:
    if: >-
      github.event_name != 'pull_request'


    steps:
      - uses: actions/checkout@v7

# Prettier main
jobs:
  check:
    if: >-
      github.event_name != 'pull_request'

    steps:
      - uses: actions/checkout@v7
```
