#### Avoid extra blank lines after YAML folded scalars (#20475 by @splincode)

With `--prose-wrap never`, Prettier no longer adds an extra blank line before the next mapping key when a folded block scalar is followed by a blank line.

<!-- prettier-ignore -->
```yaml
# Input
foo: >-
  value

bar: baz

# Prettier main (before)
foo: >-
  value


bar: baz

# Prettier main (after)
foo: >-
  value

bar: baz
```
